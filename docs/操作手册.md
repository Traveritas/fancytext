# 花式文字 FancyText — 操作手册

托盘常驻的花式文字转换弹窗。`Ctrl+Alt+F` 唤出，选中的文字自动带进来，130 种样式实时预览，`Enter` 复制全文并收起。

**C# / .NET 10 / WPF，零第三方 NuGet 依赖，自包含单文件 exe**（无需安装 .NET）。转换引擎是声明式纯数据管道：内置样式和外部样式包走同一套定义，样式包里没有可执行代码。

## 使用

**键盘**

焦点全程留在输入框，从唤出到复制不需要碰鼠标；按钮不进 `Tab` 链。

| 分类 | 按键 | 作用 |
|---|---|---|
| 全局 | `Ctrl+Alt+F` | 唤出弹窗（设置页可重新录制；也可双击托盘、或再次运行 exe） |
| 浏览 | 直接打字 | 实时预览（150ms 防抖，预览只转换前 64 个字素，复制时才转全文） |
| | `↑↓` | 在样式列表里移动 |
| 复制 | `Enter` | 复制选中样式的**全文**转换并收起（族条目 = 钻入，返回行 = 钻出） |
| | `Ctrl+R` | 在当前列表里随机选一个样式 |
| 收藏 | `Ctrl+D` | 收藏 / 取消收藏（⭐） |
| 筛选 | `Tab` / `Alt+↓` | 展开 / 收起分类筛选菜单（菜单里 `↑↓` 选择、`Enter` 应用） |
| | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换到下一个 / 上一个筛选（循环） |
| 家族 | `→` / `←` | 族条目钻入 / 返回上一级 |
| 按钮区 | 列表顶部再按 `↑`，或非族行按 `→` | 进入按钮区；`←→` 在「全部 ▾」/⭐/🕘 间循环，`Enter` 激活，`↓` / `Esc` 回列表并恢复原选中 |
| 退出 | `Esc` | 逐层：关菜单 → 回列表 → 退出钻取 → 收起弹窗 |

取舍：列表区非族行的 `→` 用来进按钮区，所以输入框里的光标没法用键盘右移。

**家族钻取**：翅膀、藏式花纹、边框、删除线、菊花体、包围字、无衬线系等 ≥4 个的同族样式，在「全部」和分类视图里折叠成一行族条目（族名 + 数量 ▸ + 代表预览），`Enter` 钻入只看该族。收藏 / 最近视图始终平铺。样式包按包名归族。内置样式归哪个族由 `StyleFamilies.cs` 里的显式成员表决定，与 ID 前缀无关。

**鼠标**：单击选中、双击复制；「全部 ▾」下拉选分类；⭐ / 🕘 切收藏 / 最近；点击弹窗外自动收起；拖动顶部空白移动窗口。

**预填**

| 选项 | 默认 | 说明 |
|---|---|---|
| 唤出时预填选中文字 | 开 | 弹窗先出现，后台用 UI 自动化（UIA）只读其它应用中选中的文字，读到后回填；你已经开始打字则不打断。不动剪贴板，主流浏览器 / Office / 记事本都支持 |
| 预填兼容模式（模拟复制） | 关 | UIA 读不到的应用改用模拟 `Ctrl+Insert` 复制兜底，读完立即还原剪贴板。只备份还原纯文本格式，刚复制的内容可能进入 Win+V 剪贴板历史 |
| 唤出时预填剪贴板文字 | 关 | 打开后，读不到选中文字时用剪贴板内容。注意：刚复制的密码之类会明文显示在弹窗里 |

**设置**（托盘右键 → 设置，或 `FancyText.Desktop.exe --settings`；全部即时生效）

| 分组 | 内容 |
|---|---|
| 个性化 | 语言（中 / 英 / 跟随系统）、主题（浅色 / 深色 / 跟随系统）、背景材质（Mica / 纯色）、强调色（预设 / 自定义 / 跟随系统）、预览字号、减少动效 |
| 快捷键 | 点击后按下新组合键录制；须含 `Ctrl` / `Alt` / `Shift` / `Win` 之一；被别的程序占用时保留原热键并提示 |
| 行为 | 开机自启动、上面三项预填、复制后收起、弹窗位置（鼠标附近 / 主屏居中） |
| 样式包 | 见下一节 |

启动时热键如果已被别的程序占用，托盘提示会写明，可以先双击托盘唤出，再到设置里换一个键。

## 样式包

一组样式存成一个 `.json` 文件，一文件一包。

| 入口 | 说明 |
|---|---|
| 官方包 | exe 内嵌 5 个：华丽装饰（32）、叠加特效（28）、颜文字（22）、星月夜（9）、生僻变换（4）。设置 → 样式包一键安装；程序更新带来新版内容时提示 [更新] |
| 在线获取 | 「获取更多样式包…」拉取 [fancytext-styles](https://github.com/Traveritas/fancytext-styles) 索引仓库（raw 直连，失败回退 jsDelivr 镜像），一键安装 |
| 导入 | 「导入样式包…」选文件；或把 `.json` 放进 `%LOCALAPPDATA%\FancyText\styles\`（没有目录监听：放好后点「重新加载」或重启程序；直接改了 styles 里的包文件也一样）；命令行 `fancy --import 包.json` |
| 管理 | 每个包可停用 / 启用（不删文件）、卸载；损坏的包标红、只能卸载；展开行可看包内每个样式对当前文字的实时预览 |

校验只拦会导致加载失败的内容（格式错误、样式 ID 与内置或其他包冲突、孤立代理对 / 控制字符、超限参数）。覆盖已装的同名包、输出膨胀过大这类「可能有问题」的情况照常安装，状态行给出提示。坏包最多让自己的样式失效，不会拖垮程序。

做新包：把 [样式包规范](样式包规范.md) 丢给 AI 助手让它照着写，再用桌面版「导入样式包…」检查（报错逐条列出，展开行即可预览）；装了源码的话也可以用 `fancy --import` 或下面的 `audit` 命令。可直接导入体验的示例见 [sample-pack.json](sample-pack.json)。

## 命令行工具 `fancy`

开发 / 脚本用途，与桌面版共用引擎、收藏和样式包目录。框架依赖发布（约 1MB），需要本机装 .NET 10 运行时。

```bash
dotnet publish src/FancyText.Cli -c Release -r win-x64 -p:PublishSingleFile=true --self-contained false

fancy "你好 Hello"          # 全部样式表格预览
fancy --list                # 样式 ID 清单
fancy bold-script "Hi"      # 单样式，只输出结果（可管道）
fancy --random "你好"       # 随机样式
fancy --json "你好"         # JSON 输出（供其它程序消费）
fancy --import 包.json      # 导入样式包
fancy --packs               # 列出已安装的样式包（含停用标记）
fancy --remove 包名         # 卸载样式包
fancy --online              # 列出在线索引；--online-install <id> 安装
fancy --help / --version
fancy bold -- --text        # -- 之后全部当文本
```

退出码：0 成功、1 操作失败、2 参数错误（含未知选项）。`--json` / `--random` 后的位置参数全部当作文本。

## 性能（实测）

Win11 26100，.NET 10，2026-10 复测：

| 状态 | 工作集（任务管理器「内存」） | 提交内存（私有） |
|---|---|---|
| 启动后从未唤出（尚未修剪） | ~130–145MB | ~70–80MB |
| 首次唤出（字体 / 词典 / 动画预热） | ~210MB | ~130MB |
| 之后每次唤出 | ~60–110MB | ~145–155MB |
| 收起 1.5s 后（修剪工作集） | **~3–12MB** | ~145–155MB |

连续唤出 / 收起 15 轮，提交内存在第 3 轮后稳定在 145–155MB，无持续增长；.NET 8 同流程测得数值基本一致。修剪的是工作集，提交内存不会因此下降。

| 指标 | 数值 |
|---|---|
| 发布包 | zip 约 62MB，解压后单个 exe 约 151MB（含 .NET 运行时与 WPF） |
| 引擎基准 | 全目录（内置 + 5 个官方包，225 个样式）× 64 字输入，约 1–2ms/次（`tests` 的 `bench` 子命令） |

轻量化的几条做法：

- **有界预览**：预览只转换前 64 个字素、输入 150ms 防抖，开销与文字长度解耦；`Enter` 时才转全文。
- **按需加载**：简繁 / 拼音 / 火星文词典 gzip 嵌入，第一次用到才解压。
- **系统材质**：圆角与 Mica 背景走 Win11 DWM，零应用侧缓冲。曾实测 `AllowsTransparency + DropShadowEffect` 会把工作集从 ~145MB 推到 ~190MB，已弃用；动效只动 Opacity / 位移，跟随系统动画开关与「减少动效」。
- **收起即修剪**：隐藏 1.5s 后 `EmptyWorkingSet`。
- **不出豆腐块**：内置 GDI 字体覆盖库，组合符按码点实时解析到已安装的系统字体，免配置。

## 数据与诊断

所有数据都在 `%LOCALAPPDATA%\FancyText\`：

| 文件 | 内容 |
|---|---|
| `desktop.json` | 桌面版设置 |
| `state.json` | 收藏 / 最近 / 语言 / 停用的包（与 CLI 共享） |
| `styles\` | 已安装的样式包，一文件一包 |
| `diag.log` | 诊断日志，默认不写 |

设置文件和状态文件都是原子写（先写临时文件再替换），写到一半断电不会坏；`state.json` 损坏时会留一份 `.bad` 备份再按空状态启动。

排查预填失败等问题：设环境变量 `FANCYTEXT_DIAG=1` 后启动，原因会写进 `diag.log`。

## 构建与测试

需要 .NET SDK 10（`global.json` 锁定 10.0.x）。

```bash
tools/package.ps1                                            # 打包 dist/FancyText.Desktop-x.y.z-win-x64.zip
dotnet run --project tests/FancyText.Core.Tests              # 引擎测试（336 项断言；失败退出码 1）
dotnet run --project tests/FancyText.Core.Tests -- demo "你好 Hello"   # 不进 UI，打印全部样式效果
dotnet run --project tests/FancyText.Core.Tests -- bench     # 性能基准
dotnet run --project tests/FancyText.Core.Tests -- audit 我的包.json   # 样式包与内置样式查重，有重复返回 1
```

版本号统一在 `Directory.Build.props`。`tools/` 下另有一批 UI 验证脚本（热键、主题、长文本、内存测量等）。

## 已知限制

- 魔鬼文字是随机的，复制出来的形态和预览不完全一样。
- 组合符的显示效果取决于对方的平台和字体：手机和游戏里最好，部分电脑字体会显示方块。
- 火星文是逐字查字典替换；「还原」尽力而为，部分火星字形对应多个原字。
- 拼音按单字取最常用读音，没有词级多音字消歧（如「重庆」）。

## 关于 Command Palette 插件

项目最早是 PowerToys Command Palette 插件。SDK 的列表页模型承载不了桌面版的交互和渲染，宿主进程常驻 200MB+ 也不在本项目可控范围，于是转成独立桌面版；插件已停止维护并从仓库移除，代码留在 git 历史里。早期调研与决策记录见 [archive/](archive/README.md)。
