# 样式包规范（schemaVersion 1）

样式包 = 一个 JSON 文件、一组纯数据样式。不含可执行代码、不发起网络请求；导入仅经本地校验后写入 `%LOCALAPPDATA%\FancyText\styles\`（一文件一包，同包名覆盖 = 升级）。

- 可运行的完整示例：[sample-pack.json](sample-pack.json)（每个样式演示一种写法，可直接导入体验）
- 在线获取：设置 → 样式包 → 获取更多样式包（索引仓库 [Traveritas/fancytext-styles](https://github.com/Traveritas/fancytext-styles)）
- 本文即 `StylePack.cs` 注释所指的「docs 样式包规范」；强校验逻辑以 `StylePacks.ParseJson/Validate` 为准

## 包结构

```jsonc
{
  "schemaVersion": 1,              // 必须为 1
  "name": "我的包",                 // 必填，决定安装文件名与界面分组；建议不用「扩充/扩展」后缀
  "author": "作者",                 // 可选
  "description": "一句话简介",      // 可选
  "styles": [ /* ≥1 个样式，≤200 */ ]
}
```

## 样式字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✓ | kebab-case（小写字母/数字/连字符，≤64 字符），**加包名前缀做命名空间**（如 `mars-`）；不得与内置样式或其他包冲突（冲突整包拒装） |
| `name` / `nameEn` | ✓ / 可选 | 显示名（≤48 字符）；建议尾部带示例字符（如 `三叠字 焱`） |
| `category` | ✓ | 内置 6 类（`effect` / `latin-fancy` / `decoration` / `transform` / `chinese` / `encoding`）**或任意自定义类别**（≤24 字符，界面原样显示，如 `颜文字`）——自定义类别的样式在主列表直接平铺，不按包折叠 |
| `note` / `noteEn` | 可选 | 机制说明（≤200 字符）；官方包风格：`动作（op 名）：码点 U+XXXX + Unicode 正式名` |
| `steps` | ✓ | 1–16 个步骤，按序组成管道 |

## 步骤（op）一览

| op | 必填字段 | 语义 / 限制 |
|---|---|---|
| `mapReplace` | `map` | 内联字符映射；键=单个 BMP 字符，值 ≤8 码元；每样式全部映射合计 ≤2048 条 |
| `useMap` | `map` | 引用内置映射表（35 张白名单：bold/italic/script/fraktur/…/circled/squared/fullwidth/leet/martian 等，见 `KnownTransforms`） |
| `appendMark` | `mark`（可选 `repeat` 1–8） | 每字素后叠组合附加符号（如 U+0307 上加点）；mark ≤4 码元；**层数建议 ≤4**（行高会撑开） |
| `wrapString` | `prefix`、`suffix` | 整串前后缀，各 ≤8 码元 |
| `wrapEach` | `prefix`、`suffix` | 逐字素前后缀，各 ≤8 码元 |
| `spacing` | `separator` | 字素间插入分隔符，≤4 码元 |
| `reverse` | — | 按字素倒序 |
| `algorithm` | `name` | 内置算法（19 个 kebab 名：zalgo-mini/…/morse/base64/rot13/简繁转换/拼音等，见 `KnownAlgorithm`） |
| `ifChanged` | `inner`（单步骤） | 守卫：上一步零命中则整段不适用（原样返回）；不能嵌套守卫 |

## 上限与健康度

单文件 ≤2MB；`mapReplace` 键单 BMP 字符；所有字符串禁孤立 UTF-16 代理对与 C0/C1 控制字符；JSON 宽容（camelCase、允许注释与尾逗号）。

## 官方收录标准（2026-09 拍板）

只收**内置没有的原子效果**与**无法靠组合模拟的独占能力**：

- ✅ 新符号/新码点的原子装饰、新组合符、反向表（解码）、静态注音映射
- ❌ 与内置同款效果（如 ✧･ﾟ 边框内置已有）、力度档（同一符号叠 N 层 = 用户多转换几次）、多步组合管道（两步转换即可拼出）

投稿前先 grep `StyleCatalog*.cs` 的 wrapString/spacing/appendMark 参数比对，或直接跑重复审计工具（签名级 + 映射子集级）：

```powershell
dotnet run --project tests/FancyText.Core.Tests -- audit 我的包.json   # 发现重复输出 [DUP]/[SUBSET] 并返回 1
```

## 发布渠道

1. **分享给朋友**：直接把 `.json` 文件发对方，双击导入或放进 styles 目录。
2. **在线索引**：向 [fancytext-styles](https://github.com/Traveritas/fancytext-styles) 提 PR——`packs/` 放包文件（ASCII 文件名）+ `index.json` 加条目（`packName` 与包内 `name` 一致；`downloadUrl` 主通道 raw 直链 + `mirrorUrl` jsDelivr 镜像，仅 HTTPS）。
3. **官方内嵌**（仅官方包）：放进 `src/FancyText.Core/Resources/bundled/` 即随程序分发。

## 验证

```powershell
# 本地导入（含全部校验）
fancy --import 我的包.json
# 试转换
fancy my-style-id "测试文本"
# 在线安装
fancy --online; fancy --online-install <索引id>
```

桌面版设置 → 样式包 中的行内展开预览可逐样式实时验证；坏包会被逐条指出原因且不拖累其他包。
