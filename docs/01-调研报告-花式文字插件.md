# PowerToys 命令面板「花式文字转换」插件 — 调研报告

> 调研日期：2026-09-11
> 调研方式：4 个并行子任务（插件生态 / 英文样式 / 中文样式 / 开源实现），全部结论附来源链接。

---

## 0. 摘要（TL;DR）

1. **同类插件不存在**：官方画廊 83 个扩展逐一核对 + GitHub 中英文搜索 + 老 PowerToys Run 插件清单，均无「花式文字 / Unicode 字体转换」插件。这是生态空白，且官方有现成的 Gallery 分发渠道。
2. **最接近的插件**：Change Case（大小写/命名风格转换，证明交互模式可行）、Symbols and Emojis（证明 Unicode 字符集可行）、老 Run 的 UnicodeInput（证明字符映射表方案可行）。
3. **样式共收集 150+**，全部可归结为 **4 种正交机制**：① 查表映射（Unicode 区段/火星文字典）、② 组合附加符号逐字叠加（菊花体、Zalgo、删除线、花藤体）、③ 装饰字符插入（括号翅膀、逐字包围、边框）、④ 拼写/方向变换（倒转、镜像、leet）。
4. **关键认知修正**：
   - **菊花体 ≠ 花符号 ❀**。真实机制是每字后附加西里尔组合符 U+0488 ҈ / U+0489 ҉ / U+A670 ꙰ / U+A672 ꙲，渲染成围绕整个字的圆圈/噪点。（站长字体网的 "Aa菊花体" 是一款真字体渲染成图片，属同名不同物。）
   - **魔鬼文字 = Zalgo**：每字随机叠加「上/中/下」三组组合符（主区间 U+0300–036F），强度可调。
   - **花藤体** = 希腊 ζ + 泰文 ั + 组合符 ͡ 拼成藤头「ζั͡」，加爪哇文 ꦿ、巴厘文 ᭄ 等组合符粘字，结尾缀 ✾✿❀。
   - **火星文** = 平行字典逐字替换（开源 MIT 字典 cnchar 有 2088 字）。
5. **可复用资源充足**：JS/Rust/Go 生态有多份 MIT 映射表（合计 60+ 样式可直接抄数据），Zalgo 有现成 C# 实现（MIT）；C#/NuGet 生态本身接近空白——正好由本插件填补。
6. **技术栈**：C# / .NET 8 / WinUI 3，NuGet 包 `Microsoft.CommandPalette.Extensions`（0.11.x，含 Toolkit），MSIX 打包，可提交官方 Gallery。

## 2. 转换样式全集（150+，按机制分类）

四种正交机制即可覆盖全部样式（实现建议见第 4 节）：

- **A. 查表映射** `map_replace(s, dict)` — 每字符查表替换
- **B. 组合符叠加** `append(s, mark, n)` — 每字符后追加 1~N 个组合附加符号（Combining Mark），渲染时叠在前字上，**中英通吃**
- **C. 装饰插入** — `wrap_string(s, pre, post)` 整串包围 / `wrap_char(s, pre, post)` 逐字包围
- **D. 拼写/方向变换** — 逆序+映射（倒转/镜像）、替换规则（leet、火星文）

#### A5. 火星文（中文专属）

`你好` → `伱恏`；`我爱你` → `莪愛伱`。机制 = 简繁转换 + 异体/生僻字平行字典逐字替换 + 谐音（Ьú）+ 日文假名の + 装饰符号ゞ。开源 MIT 字典：cnchar `spark-simple.json`（2088 字，两条等长平行字符串按索引对应）；更大覆盖：MartianText（3500 字，**无 License**）。来源：<https://www.qqxiuzi.cn/zh/huoxingwen/hxw.html>

### 2.B 组合附加符号类（中英通吃，中文特效字核心）

通用机制：每字后追加 1~N 个组合附加符号，渲染时叠加到前一字上。**对汉字同样有效**。

#### B6. Zalgo / 魔鬼文字 / 诅咒文字 / 故障文字

`你好` → `̸̈́̃你好̸̛̫̭̋`；`Zalgo` → `Z̸̷̳a̷l̴g̕o̡`。

机制：从「上方/中间/下方」三组组合符各随机抽 N 个叠到每字上，N 控制强度（mini/normal/maxi）。码点池（MelnikovIG C# 与 Im-Rises TS 两个实现交叉验证一致）：

- **上（47–59 个）**：0300–0314、031A、033D–033F、0342–0346、034A–034C、0350–0352、035B、0357、0363–036F
- **下（38–40 个）**：0316–0320、0323–032F（部分）、0330–0333、0339–033C、0345、0347–0349、034D、034E、0353–0356、0359、035A
- **中（22–23 个）**：0315、031B、0321、0322、0327、0328、0334–0338、0340、0341、034F、0358、035C–0362、0489
- 扩展池（更强效果）：U+0483–0489、U+0591–05BD、U+064B–065F、U+1AB0–1AFF、U+1DC0–1DFF、U+20D0–20F0
- 变体：Crazy/Possessed 俄式 = 每字仅叠 U+0489 ҉；反向功能 unzalgo = 过滤上述码点。

## 4. 实现架构建议

### 4.1 转换引擎 = 4 个正交原语 + 3 级管道

```
map_replace(s, dict)      // 查表：花体/全角/火星文/倒转/镜像/leet
append(s, mark, n)        // 组合符：菊花/删除线/藏文泰文特效/Zalgo(随机三组)
wrap_string(s, pre, post) // 整串包围：翅膀/括号/边框
wrap_char(s, pre, post)   // 逐字包围：括号文/逐字花藤
```

顺序无关的样式可叠加组合（站点常见的 `𝘽̶𝙤̶𝙡̶𝙙̶` = Sans Bold Italic + U+0336），设计成「基础字体层 + 装饰层 + 边框层」三级管道即可覆盖所有站点效果。

### 4.2 交互参考 Change Case

FallbackCommand（全局按键召唤）→ 读取剪贴板/直接输入 → ListPage 展示所有样式实时预览 → 回车复制到剪贴板 → 记住最近使用。中文向样式（菊花体、花藤体、火星文）是差异化卖点。

### 4.3 注意事项

- 数学字母区段有「洞」（Script/Fraktur/Double-struck 的部分大写在 U+2100–214F），需例外表；Negative Circled/Squared 仅大写，小写回退。
- Small caps 缺 Q/X；Subscript 缺 b/c/d/f/g/q/w/y/z；Superscript 缺小写 q——回退策略要统一。
- 组合符渲染因平台/字体而异（Android/游戏内最佳，PC 部分字体显示方块），**预览 + 码点提示**很重要。
- 版权：优先 MIT 数据源（fancy-fonts-generator、cnchar）；避开 AGPL 与无 License 项目。
- 火星文/隐形字符用于游戏改名可能违反游戏条款，可在详情页提示。
