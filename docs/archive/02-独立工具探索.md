# 独立工具形态探索（FancyText.Core 的复用路径）

> 2026-09-12 · **已决策（用户拍板）：只保留 PowerToys 插件 + 独立桌面版两条产品线**；
> CLI 作为开发工具随仓库保留，网页版/VS Code 等其余形态不做。
> 桌面版采用 WPF 弹窗式转换器（全局热键 + 托盘），详见 `src/FancyText.Desktop`。

## 1. 架构现状决定了可行性

```
FancyText.Core（netstandard 级纯净库）
  ├── TextTransforms     四原语（查表映射 / 组合符叠加 / 装饰包围 / 变换）
  ├── ZalgoTransformer   魔鬼文字
  ├── LatinMaps          全部映射表
  ├── MartianDictionary  火星文字典（嵌入资源）
  └── StyleCatalog       样式目录（唯一的"产品定义"）
        ▲                ▲                    ▲
   CmdPal 扩展        CLI（已做）      未来任意宿主
```

样式目录是纯数据 + 纯函数（`Func<string,string>`），任何 .NET 宿主引用即用；
非 .NET 宿主（网页/VS Code）可通过 `fancy --json` 管道或导出数据表获得同样能力。

## 2. 形态对比

| 形态 | 复用度 | 工作量 | 分发 | 适合场景 |
|---|---|---|---|---|
| **CLI**（已落地） | 100% 引用 Core | ~0.5 天 | 单文件 exe / dotnet tool | 脚本、管道、远程会话、极客党 |
| **单文件网页** | 数据导出 + JS 引擎 ~150 行 | 1–2 天 | 一个 HTML 文件，零依赖 | 手机/临时用、demo 传播、不想装 PowerToys 的用户 |
| **独立 WinUI3/WPF 窗口 + 全局热键** | 100% | 3–5 天 | MSIX/单文件 | 不用 PowerToys 的重度用户；可加输入框内实时预览 |
| **托盘常驻** | 同上 | +1 天 | 同上 | 和剪贴板联动（复制即弹预览） |
| **VS Code 扩展** | 数据导出 + TS 移植 | 2–3 天 | Marketplace | 编辑器内转换选中文字 |
| Raycast 风格启动器 | — | — | — | Windows 无此生态，不适用 |

## 3. CLI 用法（已实现）

```bash
# 构建（产出 fancy.exe，可加入 PATH）
dotnet publish src/FancyText.Cli -c Release -r win-x64 -p:PublishSingleFile=true --self-contained false

fancy "你好 Hello"        # 全部样式表格预览
fancy --list              # 样式 ID 清单
fancy bold-script "Hi"    # 单样式，只输出结果（可管道）
fancy --random "你好"     # 随机样式
fancy --json "你好"       # JSON 输出（供其它程序消费）
```

脚本示例（PowerShell，把剪贴板转成花体再写回）：

```powershell
Set-Clipboard (fancy juhua-1 (Get-Clipboard))
```

## 4. 决策后的路线（2026-09-12 更新）

1. **PowerToys 插件**：主形态，面向 PowerToys 用户（v1.0.1+）。
2. **独立桌面版**：WPF 弹窗式转换器——全局热键（默认 Ctrl+Alt+F，`desktop.json` 可改）、
   托盘常驻、失活自动隐藏、预填剪贴板、150ms 防抖实时预览（前 64 字素）、Enter 复制全文转换；
   收藏/最近通过共享的 `%LOCALAPPDATA%\FancyText\state.json` 与插件互通。
   单文件发布：`dotnet publish src/FancyText.Desktop -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true`。
3. ~~单文件网页版~~：按决策不做。
4. ~~托盘常驻（独立于桌面版）、VS Code 扩展、多启动器适配~~：不做。

## 5. 风险与注意

- 网页版需要把 `Func<string,string>` 样式改写为声明式数据（配方）或双实现——
  建议先只导出映射类/组合符/装饰类（占 90%+），Zalgo/编码类在 JS 里手写等价实现。
- 火星文字典（cnchar MIT）在网页版分发时需保留版权声明。
- CLI 的 `--self-contained false` 依赖 .NET 8 运行时；要"拷走就用"可改 `--self-contained true`（约 +70MB）。
